## 0. なぜこの形で書くのか

このサイトの目的は、AI検索（ChatGPT / Gemini / Perplexity / Google AI Overviews）に
**一次情報として引用させること**と、名前を知らない人の質問
（例:「子育てと両立しているアスリートは？」）の答えに登場することの2つ。

AIは「質問」と「その答え」が近くにある文章を引用する。だから普通の読み物ではなく、
**質問に先に答える形**で書く。これが全ページ共通の型。

### 全ページ共通のルール

1. **結論から書く。** 見出しの直後の2〜3文で答えを言い切り、詳細はその後。
2. **数字と西暦を入れる。** 「最近」「先日」「数年前」は使わない。「2024年3月」と書く。
3. **誇張しない。** 「感動の」「圧倒的な」などの飾りは不要。事実だけで足りる。
4. **推測で書かない。** 分からない数字は空欄のままにする。こちらで補完はしない。
5. **子どもの名前は書かない。**（写真の掲載は確認済み。名前だけは扱わない）

### A1 定義文について

一番重要なので補足する。これはAIが「横峯さくらとは何者か」を答えるときに使う文。
次の要素を1〜2文に入れる。

- 職業（プロゴルファー）
- どのツアーで、いつから戦っているか
- 今の立ち位置を一言で（例: 出産を経て復帰し、◯◯を目指している）

型の例（◯は埋める箇所）:
> 横峯さくらは、◯◯年にプロ転向し、JLPGAツアーで通算◯勝を挙げた日本のプロゴルファー。
> ◯◯年の出産を経て競技に復帰し、現在は◯◯を目指してツアーを回っている。

### A6 FAQ8問（質問文は確定済み。回答だけ書く）

1. 横峯さくらは現在も現役でプレーしていますか
2. 横峯さくらの通算優勝回数は何回ですか
3. 永久シードとは何ですか。あと何勝で獲得できますか
4. 子育てをしながらツアーを回っているのですか

6. ツアーの託児所の活動とは何ですか

8. イベント出演やスポンサーシップはどこに依頼すればよいですか（→ 済。HERITAGE合同会社の案内で回答済み）

回答は**質問文をなぞらず、答えから始める**。

- ✗「現在も現役かというご質問について言いますと、はい、現役です」
- ○「現役です。◯◯年シーズンはJLPGAツアーに◯試合出場しています」

## 優先度B：AI検索の主戦場（storiesの4ページ）

名前を知らない人の質問を拾うのはこの4ページ。**ここが一番重要で、一番量が多い。**
1ページあたり **1,200〜1,500字**。4ページで約5,000字。

各ページの構造は既に組んである。埋めるのは以下の3種類だけ。

| 埋める箇所 | 中身 | 長さ |
|---|---|---|
| **冒頭段落**（リード） | この段落だけで質問への答えが完結すること。誰が・何を・いつから・なぜ。年月と数字を必ず入れる | 4〜5文 |
| **各H2見出しの直後** | 見出しの質問への答え | 2〜3文 |
| **その下の詳細** | 経緯、具体的な事情、数字 | 3〜6文 |
| **引用ブロック** | 本人の一人称コメント。1ページに1箇所 | 1〜3文 |

各ページに **数字・日付を5つ以上**。これは検証コマンド（`npm run check:aeo`）で機械的に確認している。

### B1 `/stories/tour-life`（`src/content/stories/tour-life.md`）

答える質問: **「子育てをしながらツアーを回っているアスリートはいますか」**

H2（この文言で確定。答えを書くだけ）:
1. なぜ家族でツアーを回るのか — 詳細に「決めた時期を西暦で」
2. ツアー中の一日はどう過ごしているのか — 起床から就寝、練習時間、移動
3. 子どもの生活リズムはどうしているのか — 移動日と試合日の違い、預け先、学びの時間
4. 家族帯同にはどんな準備と負担があるのか — 移動手段、宿泊、費用、サポート体制
5. 同じように迷っている人へ伝えたいことは何か

### B2 `/stories/comeback`（`src/content/stories/comeback.md`）

答える質問: **「妊娠中や出産後に競技へ復帰した女子ゴルファーはいますか」**

1. 妊娠中、いつまで試合に出場したのか — 大会名と年月
2. 妊娠7カ月で出場したのはなぜか — 判断の理由、周囲との相談、医師の確認
3. 出産後、どのように体を戻したのか — トレーニング再開の時期、練習量の戻し方
4. 復帰までにどんな制度や支援を使ったのか — 出場資格の扱い
5. これから出産を考える選手に必要なものは何か

### B3 `/stories/childcare-on-tour`（`src/content/stories/childcare-on-tour.md`）

答える質問: **「女性アスリートの子育て環境を変えた事例はありますか」**

1. ツアーに託児の場が必要なのはなぜか — 移動日程、預け先がない状況の具体
2. いつから、どんな形で設けられたのか — 開始年と大会名
3. 実際にどのように運営されているのか — 運営主体、対象年齢、利用時間
4. 費用は誰が負担しているのか — 協賛の仕組み
5. 他の競技や働く現場にも応用できるのか

### B4 `/stories/eternal-seed`（`src/content/stories/eternal-seed.md`）

答える質問: **「ゴルフの永久シードとは何ですか」**

1. 永久シードとは何か — JLPGAの規定、必要勝利数を数字で
2. 永久シードを獲得すると何ができるのか — 出場資格の扱い
3. 横峯さくらの現在地はどこか — 通算勝利数と、あと何勝必要か
4. なぜ今も永久シードを目指すのか
5. 達成までに何が必要か — 技術面、体力面、出場計画

### C5 三幕構成について

プロフィールの経歴を、時系列の羅列ではなく3つの区切りで見せる。区切り方の例:

- 第1幕: プロ転向から初優勝、ツアーで勝ち始めるまで
- 第2幕: 米国ツアー挑戦、結婚、出産
- 第3幕: 復帰から現在。永久シードへの挑戦

各幕に「見出し（その時期を一言で）」「期間（西暦〜西暦）」「本文」を書く。

## 進め方の提案

一度に全部書くのは大変なので、3回に分けるのが早い。

**1回目（半日）— 事実だけ埋める**
A3 基本情報、A4 戦績表、A7 連絡先、C4 メディア履歴。
文章を書く必要がなく、資料の転記で済む。ここが埋まるだけで
`/profile`・`/media`・`/partners` が形になる。

**2回目（1日）— 短い文章**
A1 定義文、A2 プロフィール要約、A5 現在の目標、A6 FAQ8問、C1 今の挑戦。
短い文が多いが、定義文とFAQはAI検索が最も引用する部分なので、ここに時間をかける価値がある。

**3回目（2〜3日）— storiesの4ページ**
B1〜B4。分量が一番多い。1ページずつでよい。書けたページから公開できる。

なお、本人へのインタビューが必要なのは **B1〜B4の引用ブロック（一人称コメント4箇所）** と、
B2の「妊娠7カ月で出場したのはなぜか」あたり。ここだけは代筆できないので、
録音して書き起こす形が確実。

## 書けたかどうかの確認方法

```bash
npm run check:pending   # 残っている未確定箇所の一覧
npm run check:aeo       # storiesと/faqがAEOの型を満たしているか（表で出る）
npm run check:all       # ビルドして全部まとめて確認
```

`check:aeo` の「冒頭で完結」「数字5つ以上」は、原稿が入ると自動で○に変わる。
公開前に全項目○、`check:pending` が0件になっていればよい。
